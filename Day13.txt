Constructor
>If a class name and method name are same the method is called as constructor
>Generally Constructor should be public
>Don't use any return type to a constructor
>Whenever we create object to a class a constructor invoke automatically
>we no need to call a constructor.
>If you try to call it return error.
>Types of Constructor:
1.default 2.Parameterized 3.copyconstructor 4.private 5.construtor chaining

-------------------------
Construtor chaining -> 
> If aconstructor calls another constructor, that is constructor chaining.
>have to use this method within  constructor
>this method used to call another constructor.
>Till java version 19 this method should as a first statement of aconstructor.
>Java 25 introduces flexible constructor Bodies. Can use this method anywhere within constructor.

import java.util.Scanner;

public class Main {

    static int f1 = 1, f2 = 1;
    static int count = 0;

    static int num = 2;

    // Returns next Fibonacci number
    static int fibonacci() {
        if (count == 0 || count == 1) {
            count++;
            return 1;
        }

        int f3 = f1 + f2;
        f1 = f2;
        f2 = f3;
        return f3;
    }

    // Returns next Prime number
    static int prime() {
        while (true) {
            boolean isPrime = true;

            for (int i = 2; i*i <= num; i++) {
                if (num % i == 0) {
                    isPrime = false;
                    break;
                }
            }

            if (isPrime) {
                int temp = num;
                num++;
                return temp;
            }

            num++;
        }
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        for (int i = 1; i <= n; i++) {

            if (i % 2 != 0) {
                System.out.print(fibonacci() + " ");
            } else {
                System.out.print(prime() + " ");
            }

        }

        sc.close();
    }
}
